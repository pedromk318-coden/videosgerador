# Recursos visuais

O motor ativo não precisa de imagens externas. Ele desenha os cenários e personagens por código em cada quadro, sem IA, sem Flow e sem chave de API.

A pasta fica reservada para recursos visuais locais que poderão ser incorporados numa evolução futura do motor. A execução atual do workflow não lê imagens desta pasta.

Para entender o motor atual, consulte `src/animation_engine.py` e o README principal.
